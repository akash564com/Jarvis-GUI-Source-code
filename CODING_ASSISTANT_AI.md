# Coding Assistant AI 🤖
A personal Python coding assistant built with open-source models.

## Features
- Generates Python code with explanations
- Auto-runs and tests code
- Remembers your past queries
- Acts like a human mentor

## Quick Start
```bash
python coding_assistant_ai.py "write fibonacci function"
```

Artifacts created:
- `generated_solution.py`
- `test_generated_solution.py`
- `coding_assistant_memory.json`
